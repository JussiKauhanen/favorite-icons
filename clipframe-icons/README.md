# Clipframe icon studies

Three 1024 × 1024 vector directions for a screenshot capture and editing app.
The artwork is intentionally sparse, centered, and built from hard-edged shapes
so it behaves well with Icon Composer's depth and Liquid Glass effects.

## Recommended direction

`01-fjord-frame` is the strongest all-around mark. The cream panel reads as a
captured screen, the four open corners read as framing/cropping, and the coral
slash adds the editing action without turning the icon into a tiny UI mockup.

## Import into Icon Composer

1. Create a new 1024 × 1024 icon.
2. Add each SVG from the chosen concept's `layers` folder in numeric order.
3. Keep the background layer full-bleed and opaque.
4. Keep the artwork centered; don't add a rounded-square mask. Icon Composer
   and the system apply the final platform shape.
5. Start with subtle depth: background at the back, the main object in the
   middle, and the accent/editing mark in front.
6. Test at the smallest preview size before increasing translucency or blur.

The `master.svg` file is a flattened visual reference. The layer SVGs are the
files intended for import and adjustment.

## Suggested material treatment

- Background: opaque, no blur.
- Main frame/card: low translucency or fully opaque; soft specular response.
- Accent: fully opaque and slightly raised.
- Avoid strong shadows in the source artwork; let Icon Composer create them.

## Palette

- Fjord: `#315C5D`, warm paper `#F4EFE5`, ember `#E56B4D`
- Birch: `#E9E1D2`, graphite `#283431`, lake `#6E9E9A`
- Midnight: `#25333D`, frost `#E9F0EC`, cloud `#9DBBB8`
